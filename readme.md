# 📦 JSON Formatter & Validator

A clean and powerful **JSON tool** built with **HTML, CSS, and Vanilla JavaScript**.  
It helps you format, validate, and debug JSON instantly.

---

## ✨ Features

- 📦 Format JSON (Pretty Print)
- ❌ Validate JSON with error detection
- ⚡ Instant feedback
- 📋 Copy formatted JSON
- 🧹 Clear input/output
- 📱 Fully responsive UI
- 🎨 Developer-friendly design

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
